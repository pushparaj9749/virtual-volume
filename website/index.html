05 / BUILT FOR ANDROID. HONEST ABOUT ANDROID.

A useful utility.
Not a workaround.

Made for Android 8.0 (API 26) and newer, on devices that allow “Display over other apps”. No root or accessibility service required.

A few things worth knowing
01

Screen on means control on.

Normal apps can't receive arbitrary touch gestures while the display is powered off. The service preserves its state where allowed; the line returns when you wake and unlock.

02

Some screens stay protected.

Secure apps, payment screens and system permission dialogs may hide overlays. Android's security rules always take priority.

03

Your phone has the final say.

Battery policies and background-start restrictions can pause the service. Open the app or tap the tile to resume. Reboot restoration is opt-in and best effort.

06 / GOOD QUESTIONS

A little more clarity.

Everything you should know
before it lives on your screen.

Is this a native Android app?
Yes. The app is built in Kotlin with Jetpack Compose and Material 3. The floating control is a native Android window and changes real media volume through AudioManager. This website is a separate product — there is no WebView in the app.
What permissions does it need?
“Display over other apps” lets the compact control appear above ordinary apps. Android also requires a foreground service and its notification. Notification permission on Android 13+ is optional but recommended for the off switch. Optional haptics use vibration; optional reboot restoration uses the boot broadcast. The app requests no internet, microphone or accessibility permission.
What happens if my volume buttons are broken?
Virtual Volume is a software alternative while your screen is on and unlocked. It can adjust the phone's media volume without touching the physical rocker. It isn't a hardware repair and can't replace buttons for power-off menus, recovery mode or arbitrary screen-off input.
Will it get in the way of other apps?
The interactive window stays compact around the line. Everything outside it remains available to the app underneath. You can adjust its size and position, or turn it off from the tile or notification when you need that exact part of the edge.
How do I install the APK?
Download the signed APK on your Android phone and open it. Android may ask you to allow your browser or file manager to “Install unknown apps”. Allow that source only if you trust it, then follow the five-screen setup. Release checksums are available on GitHub. Always install updates signed with the same release key.
Does it collect any personal information?
No product analytics, accounts, cloud sync or tracking. Preferences are stored locally in Android DataStore, with app cloud backup disabled. This website remembers only your theme choice in your browser. GitHub hosts the site and APKs and may keep standard delivery logs; the site uses GitHub's public release API to find downloads.
Why can't I see the control on my phone?
Check overlay permission, wake and unlock the screen, then open the app and tap Resume control. Protected apps can intentionally hide it. Some Android Go devices don't allow this overlay permission at all. If your manufacturer's battery policy stops it, use the tile or the app to resume; the app never bypasses Android's restrictions.
