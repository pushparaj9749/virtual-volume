# Virtual Volume — website

Static marketing site (no framework, no build step, no tracking).

- `index.html` — single-page landing (hero, how-it-works, features, gesture demo, compatibility,
  Quick Settings, privacy, FAQ, download, footer).
- `assets/css/styles.css` — hand-written, dark/light theming, mobile-first, `prefers-reduced-motion` aware.
- `assets/js/main.js` — theme toggle, scroll reveals, two gesture simulations.
- `assets/js/download.js` — resolves the newest release APK from the GitHub API at runtime.
- `assets/img/*` — original brand assets; `apple-touch-icon.png`, `icon-512.png`, `og-cover.png` are
  generated by `tools/generate_web_icons.py`; `hero-og.jpg` is the social/hero render.

Deployed to GitHub Pages by `.github/workflows/website-deploy.yml`.
